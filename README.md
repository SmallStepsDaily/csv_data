# 数据存放格式
+ 以人名定义文件夹，每个文件夹定义对应生物组培养细胞的日期，文件夹下存放子文件夹
    + `表型表征值`
    + `FRET表征值`
    + `药效评估`
+ 除了子文件夹外，还存放特征文件，为FRET特征和表型特征
    + `FRET.csv` 表示FRET特征文件
    + `FMNB_` 开头的csv文件表示基于FRET转录后的表型特征提取文件
    + `MNB_` 开头的csv文件表示基于细胞核和线粒体染色图像区域的表型特征提取文件
    + `MB_` 开头的csv文件表示基于线粒体区域的表型特征提取文件
    + `FB_` 开头的csv文件表示基于FRET通道识别的单细胞的表型特征提取文件
